# 🌸 Womxn360: AI-Powered Women's Health Ecosystem

**Womxn360** is a comprehensive, multi-domain digital health platform designed to bridge the gap in women's healthcare. It integrates **Generative AI**, **Voice Interaction**, and **Medical Risk Algorithms** into a single, persistent ecosystem covering Menstruation, Pregnancy, Postpartum, and Menopause.

## 🚀 Key Features
*   **Context-Aware AI Chatbot ('Eve'):** Powered by Google Gemini, Eve remembers your pregnancy week or cycle phase to give personalized medical advice.
*   **Voice-Activated Interface:** Full Speech-to-Text and Text-to-Speech support for accessible interaction.
*   **Risk Prediction Engine:** A rule-based algorithm to screen for **PCOS** risks based on BMI, dermatological, and gynecological symptoms.
*   **Hygiene & Safety Hub:** Features a **TSS (Toxic Shock Syndrome)** prevention timer and a Vaginal Discharge Decoder.
*   **Persistent Tracking:** Unified dashboard for Period, Pregnancy, and Menopause with no data loss.
*   **Clinical Reporting:** Generates downloadable **PDF Medical Reports** for doctor consultations.

## 🛠️ Tech Stack
*   **Backend:** Python, Flask
*   **Database:** SQLite, SQLAlchemy ORM
*   **AI Engine:** Google Gemini API (LLM)
*   **Frontend:** HTML5, CSS3, Bootstrap 5, Jinja2
*   **APIs:** Web Speech API (Voice), Chart.js (Visualization)

## ⚙️ How to Run Locally
1.  **Clone the repo:**
    ```bash
    git clone https://github.com/soujanya0109/Womxn360-AI-Health-System.git
    cd Womxn360-AI-Health-System
    ```
2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Add your API Key:**
    Open `app.py` and replace `GOOGLE_API_KEY` with your own Google Gemini API key.
4.  **Run the App:**
    ```bash
    python app.py
    ```
5.  **Access:** Open `http://127.0.0.1:5000` in your browser.
